HOW TO READ A ROW

Implied value is the slice of a launch's predicted value that reaches farmers and the community — not the whole FDV. Rank range is where the row lands across 200 refits: a narrow range is a sturdy rank, a wide one is a coin toss. Verdict nets the implied value density against the plan's own 3-month cost: FARM it, farm it THIN (small size only), or SKIP it.
